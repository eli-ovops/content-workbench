# Draft Desk

**Write once. Keep your versions. Adapt for each platform.**

The draft is in one place, its sources are somewhere else, and the version prepared for another platform is in a third file. Draft Desk brings those pieces into a local writing workflow.

The implementation and notes cover drafting, source references, version history, platform-specific text, and preparation packages.

## What you can explore

- A shared draft with separate platform-specific changes.
- Versions, source notes, and text-based shot notes kept with the writing.
- Explicit save and conflict handling.
- Export, recovery, and recycle-bin workflows.

## Public snapshot status

The repository contains a local implementation and historical records from a personal workflow. Some setup notes still use machine-specific paths, so a portable setup for a fresh clone has not been verified.

The workbench does not call publishing platforms, models, or media services. Historical tests on the original machine do not establish that this public copy is ready to run elsewhere. Some linked working notes remain in Chinese.

The new presentation material and the owner's original contributions are published under the [MIT license](LICENSE). Third-party material keeps its own licenses and attribution; this license does not relicense it. Existing source and license files have not been changed by this update.
