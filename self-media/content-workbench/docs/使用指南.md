# 使用指南

默认工作空间已统一，原两份稿件在列表中可直接查看和修改副本。原库保留。启动、停止、恢复只使用工程根标准入口；旧已验收启动器与标准入口指向同一根。浏览器会记住当前稿件，刷新和从统一网址重开时恢复当前位置。

1. 在Finder双击“启动内容工作台.command”。它自动启动本机服务、连接Chrome并打开稿件，直接开始写，不输入编号。同一浏览器会话有效期间可直接打开 http://127.0.0.1:56442/ 。服务重启或会话到期时，再双击启动器即可；不需要先打开网页生成编号。启动器打开的Chrome是长期使用入口。
2. 在“写稿”粘贴已有选题卡/脚本文字。资料日期未知可留空；许可到期需带时区，例如2026-10-13T09:00:00+08:00。来源属性默认待核，未实测事实保留待核。
3. 点“保存”，看到“已保存 · 时间”确认（悬停状态可查看revision）。保存按不超过40KiB的文字块提交，全部字段成功才显示已保存；冲突/超限/失去会话仍保留页面编辑，点“下载当前编辑”可从本页缓冲区挽救。此挽救文件不是正式恢复包，可把文字重新粘贴回来。
4. 在“版本与画面”冻结已保存稿件。旧版本保留；选择旧版可复制到新草稿。镜头备注每行一项，默认绑定第1段；可用“[段落2] 需录什么”指定段落。未绑定或旧适用版本要重新检查，不自动沿用审片结果。
5. “平台文案”只填一次通用文案，各平台只填差异。空的差异字段继承通用稿。平台语言是目标，工具不转换；繁体文案需要自己核对。正文hashtag是计划，YouTube后台标签独立，均不表示原生挂载。
6. 为公共文字声明自有或来源依据，核对语言/专名，保存后点“确认本站公开文字”。该确认只对本次启动与确切依赖有效；改稿/改许可/重启后需复核。真实使用中的公开决定仍由本人负责，示例确认不证明客户或版权许可。
7. 内部DRAFT不必冻版，但也必须已保存。冻结包须脚本冻版及选择平台。公开条件不足的站点只进入内部包；受影响公开内容被剔除。生成后可下载内部恢复包或独立公开文字包，公开包不附内部JSON。
8. “资料与恢复”可手动刷新正式源，显示原值/时间/差异；active改变不会改原关联。选择本工具完整内部包创建新根，随后双击副本目录的“启动隔离副本.command”。导入许可与核准仅是历史，不自动生效。

九个模板：小红书、B站、国内抖音、微信视频号、YouTube、LinkedIn、X、微博、TikTok。国内简体、海外繁体，模板取自账号Owner 2026-10-09资料，非实时账号能力。桌面与390px窗口已验，不能据此称手机能连接loopback。

本轮交互完善：
- 标题下“删除稿件”移到回收站，正文、来源和所有版本保留；左侧底部回收站可单篇恢复。删除提示也提供即时恢复。未保存编辑须先保存，删除最后一篇后可以直接新建。
- 左栏可按标题或版本文字查找稿件；筛选不修改当前稿。
- 正文右上“专注写稿”隐藏导航和资料；再次点击或Esc返回，保留当前编辑。
- 标签页支持左右方向键与Home/End；⌘S显式保存。
- 版本区展示所选版和它的上一版。更换适用版本属于稿件修改，需保存并重新核对依赖。
- 平台区可分别复制本站标题、正文、话题，YouTube后台标签独立复制；复制当前页面文字不等于已审核或发布。复制受浏览器限制时，请在文字预览手动选择复制。
- 提示可关闭；普通成功提示在切页时收起，错误保留到手动关闭或重新读取稿件。

2026-10-13写稿交互：新建会回到写稿页并选中标题；新稿默认名带序号避免重名。未保存时切换、新建或打开回收站，可返回编辑，或保存后继续。列表按最近活动排序，显示版本及本机时间；搜索无结果时可清除搜索。
