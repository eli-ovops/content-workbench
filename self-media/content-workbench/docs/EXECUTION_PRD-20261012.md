## 4. 保存、恢复、技术与异常

软件根为 `/Volumes/EXTERNAL/自媒体/content-workbench`，默认数据根为其 `data/`、导出为其 `exports/`，实际运行登记rootId/介质及允许写根；恢复选择的新根独立登记。主路径是显式保存，无两秒承诺。同一数据根仅一个写实例：跨进程排他锁、串行写队列、提交前核持久revision；第二进程换端口也不能写同根。残留锁核进程身份/根，不直接删锁。JSON同目录临时写→完整校验/持久化→替换自有当前稿，保留上一有效完整副本；普通启动发现缺库/损坏/未来schema/挂载丢失/根身份不符停止写，不能自动初始化空库。

容量默认单次载荷1MiB、50档案；总硬上限50MiB计当前数据、历史、备份、完成/失败导出及inflight预留。新内容/冻版/导出在45MiB停新增，剩余5MiB仅用于受限保存/撤销与恢复现场，总上限不增长；单写协调点先预留再写。满额保旧数据、可复制/浏览器下载当前编辑，撤销立即停止公开生成/下载；预留仍不足只读并报具体原因，不自动删文件。401/409/413、断盘、写失败保留页面编辑；浏览器挽救下载只用已打开编辑缓冲区，不绕服务器认证读取。保存未知先核revision/摘要，不能盲重发。工具确认的是已提交数据，不保证未保存文本或硬崩溃零丢失。

恢复仅本工具支持的COMPLETED内部包→新根→核schema/摘要/全关系→新rootId。嵌套ID统一新命名空间，保originalRef；同包恢复两次互不引用，拒绝悬空/跨档案关系与不支持schema。路径/正式PASS/核准/读取及公开许可都是历史；不授读取、公开或业务权限，公开确认必须重新针对新版本产生。不搬原媒体、不合并当前库、不自动切为日常库。
